# Code of conduct

Be respectful and specific. Critique code and behavior, not people. Harassment, discrimination, threats, doxxing and unwanted sexual attention are not welcome. Respect boundaries and keep confidential information private.

Maintainers may edit or remove harmful contributions, close discussions, or restrict participation. Enforcement should be proportionate, explained where appropriate, and applied consistently. To report a concern, contact a repository maintainer through a private channel listed on their GitHub profile. Do not post a person's private information in an issue.
